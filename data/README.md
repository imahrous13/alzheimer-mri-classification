# Data

The MRI images are **not** committed (they are large and publicly downloadable). This folder is
the expected location for the dataset used by the pipeline.

## Expected layout

```text
data/
├── raw/
│   ├── original/<Class>/*.jpg      # 6,400 original scans
│   └── augmented/<Class>/*.jpg     # 33,984 augmented scans
└── processed/                      # generated by the pipeline (gitignored)
    ├── image_manifest.csv
    ├── dataset_splits.csv
    ├── split_summary.json
    └── features/                   # cached HOG features
```

`<Class>` is one of `MildDemented`, `ModerateDemented`, `NonDemented`, `VeryMildDemented`.

## How to obtain it

```bash
kaggle datasets download -d uraninjo/augmented-alzheimer-mri-dataset -p data/raw --unzip
# The archive extracts as AugmentedAlzheimerDataset/ and OriginalDataset/.
# The pipeline recognizes these names and normalizes them to augmented/ and original/.
```

Source: <https://www.kaggle.com/datasets/uraninjo/augmented-alzheimer-mri-dataset>.

## Regenerating processed outputs

After placing the raw images:

```bash
PYTHONPATH=src python -m alzheimer_mri.audit --workers 12
PYTHONPATH=src python -m alzheimer_mri.splits --phash-radius 0 --seed 42
```

See the top-level `README.md` and `docs/DATA_CARD.md` for dataset statistics and limitations.
